# 로마 콘크리트 A2 · R3.1 파일 전달 수정본

2026-10-14 (Asia/Seoul). 생성·열기 검증을 마친 파일 묶음이다. GitHub에서 아래 파일을 연 뒤 **Download raw file**로 내려받을 수 있다. 클라우드 내부 파일 경로는 다운로드 링크로 사용하지 않는다.

| 파일 | 용도 | 규격 |
| --- | --- | --- |
| [a2-print.pdf](a2-print.pdf) | 인쇄용 원고 | A2 420×594mm 재단, 사방 3mm 여분, 426×600mm 페이지, 300ppi CMYK, FOGRA51 |
| [a2-preview.pdf](a2-preview.pdf) | 가벼운 화면 열람 | A2 420×594mm, 144ppi sRGB 배경, 검색 가능한 원래 글자와 내장 글꼴 |
| [a2-300ppi.png](a2-300ppi.png) | 이미지 출력 | A2 재단 내부, 4961×7016px, sRGB |

인쇄 PDF의 버전 표기를 PDF 1.7로 교정하고 배경의 무손실 압축 표현만 바꿨다. 원래 CMYK 픽셀 5034×7088개, ICC, 853개 비공백 문자, 8개 내장 글꼴, 벡터 그리기, 모든 페이지 영역은 정확히 같다. 무손실 압축 후 파일은 50,396,227바이트다. 원본은 별도 보존했다.

독립 MuPDF 디코더에서 CMYK 전체 바이트를 대조했다. Poppler에서 전체 페이지와 300ppi 확대 4곳을 직접 렌더링했고 원본과 픽셀 차이가 0이다. 모든 배경 픽셀의 총 잉크량은 최대 300%이며, 기존 인쇄 점검 18개를 통과한 원고의 데이터를 그대로 유지한다. [인쇄 데이터 대조](print-verification.json), [기존 인쇄 점검](print-preflight.json), [압축 비교](print-compression.json)를 함께 제공한다.

화면 열람 PDF는 배경만 144ppi JPEG로 줄였다. 이 파일의 작은 용량을 인쇄 원고의 해상도 또는 압축 조건으로 해석하면 안 된다. 인쇄에는 `a2-print.pdf`를 사용한다. [열람용 검증](preview-verification.json)과 [파일 해시](manifest.json)를 확인할 수 있다.

이 판본은 실제 Blender 수정·재렌더·독립 재심사를 거친 로컬 R3 모델과 R3.1 글을 합성한 결과다. 호출 가능한 Figma 도구가 없었고 API 접근도 차단되어, 최신 Figma 원본과의 동일성 및 Figma 반영은 확인하지 못했다.

파일의 기존 PDF/X 메타데이터는 유지했지만 독립 ISO PDF/X 인증을 주장하지 않는다. 사용자 브라우저에서의 수신·열기·다운로드는 로컬 파싱·렌더링과 별도로 확인해야 한다.
