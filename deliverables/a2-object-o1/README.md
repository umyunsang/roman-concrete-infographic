# A2 object O1 · 심사 중인 후보

실제 Blender 모델 수정과 19개 인쇄 기술 검증을 마친 후보입니다. 모든 객체·전체 구성·최종 A2 원고의 독립 AAA 판정은 아직 완료되지 않았습니다. 후속 판본과 혼동하지 않도록 이 폴더는 O1로 유지합니다.

- `a2-print.pdf`: A2 420×594mm, 도련3mm, CMYK/PSOcoated_v3, 배경 약300ppi, 전체 잉크량≤300%, 포함 한글 글꼴·검색 가능한 글자.
- `a2-preview.pdf`: 열람용 작은 PDF, 벡터 글자 유지.
- `a2-300ppi.png`: A2 RGB 이미지,4961×7016.
- `roman-concrete-o1.blend`: 실제 수정 모델. 문자47개 공식NotoSansCJKkr Regular/Bold글꼴이 포함됐습니다. A2의83개 벡터 텍스트는 별도text-spec.json으로 합성합니다.
- `model-changes.json`, `manifest.json`: 실제 변경 및 SHA기록.

현재A2에 보이는236모델과 숨김53모델을 각ID로 구분해 검토합니다. 콜로세움 본체·축소모형·받침·아레나표면도 개별대상입니다. 원본공유재질74개와배치ID를보존하고 메쉬36개를수정했습니다.

원격Figma최신판동일성·반영은 미확인인 로컬후보입니다. 원래Mac/Figma글꼴바이너리동일성은미확인이며, 실물인쇄교정과PDF/X인증은 주장하지 않습니다. 글꼴라이선스를함께제공합니다.
