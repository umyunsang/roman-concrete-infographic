# A2 객체 검토 중 후보 — O1 print2

**모든 객체의 AAA가 완료된 최종본이 아닙니다.** 현재 A2의 236개 모델과 보관된 53개 모델을 개별 검토하고 있습니다. 포함된 형태 분야 보고서는 보관 모델 53개의 1차 판정이며, 현재 A2 모델과 원고의 최종 합격을 대신하지 않습니다. 45개 AAA·8개 HOLD이고 독립 재검토는 남아 있습니다. 베스타 신전은 후속 Blender 형상 수정 중입니다.

이 PDF는 O1의 인쇄 규격 수정 후보입니다. 래스터 검정값을 378픽셀에서만 245→244로 고쳐 K≤96%를 충족하고, PDF 헤더를 1.6으로 맞췄습니다. TAC≤300%, 420×594mm trim, 3mm 도련, 실제 860자·8개 내장 글꼴을 검증했습니다. 지정된 벡터 문자 검정 정책은 보존했습니다. 정식 PDF/X 인증을 받았다는 뜻은 아닙니다.
