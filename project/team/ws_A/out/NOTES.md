## 1. [I1 흐름] CORE 길 — 가장 진한 띠 + 방향 신호
- `a_core_road.py`: 로마 가도 단면 그대로 — 돋운 노반(agger, ZB 0.12) 위 현무암 다각 포장석(`R_core_road` 회색 0.30) + 양쪽 흰 연석 띠(`R_core_curb` 0.97, 높이 0.15) + 노반 비탈(`R_core_bed` 0.86).
  측정: 길 포장 명도 135~147(배경 땅 240) → 지도에서 가장 또렷한 띠.
- 방향 신호(글 아님): 흰 돌 셰브런 상감 `R_core_chev` 27개(간격 6.2단위, 경로 순서 ①→⑤ 방향을 가리킴). 반시계 흐름(Lu et al. CHI 2020)에 대한 명시 신호.
- 시작 ①: 길을 ① 채석장 장면 앞(716,486)까지 이어 붙임(`assets/core_road_uv.json`, CORE① 글 아래 26pt) + 둥근 포장 광장(R 2.3) + 이정표 기둥 `L13_core_start_column`.
- 끝 ⑤: 길 끝을 (940,885)로 당겨 ⑤ 글과 떨어뜨림 + 도착 광장 + 길을 가로지르는 개선문 `L13_core_arrival_arch`. 광장 연석은 길이 드나드는 입구에서 끊음.
- 다리 위에도 진한 포장 띠(`bridge.py` → `R_core_road_bridgeN`, 상판 위 0.05), 다리 경사로 끝 0.16→0.30(노반 덮음).
- 길 앞(화면 아래쪽)에 서서 길을 가리는 나무는 사후 검사로 지움.

## 3. [C1·C4 밭] `a_fields_trees.py`(fill_plains 2절 대체)
- 판 두께: 바닥 띄움 0.05→0.025~0.035, 가장자리 둑(0.11 돋음) 제거, 조각 사이 틈 0.
- 기계적 반복 깨기: 지역 5곳(NE 0° / NW 12° / SW -15° / SE -9°, 구획 8.2~11.4) 격자 방향·크기 다르게, 구획 성격 섞음(섞어짓기·통밀·목초·올리브 과수원·숲·빈터).
  조각난 구획(놓인 띠 < 70% 또는 < 4개)은 통째로 버림, 다른 격자와 겹치는 띠는 SAT 검사로 버림, 밭 전용 난수.
  CORE ③④·DETAIL ③④ 정보 구역(화면 520~880 × 960~)과 물가 비탈(높이 < 0.02)엔 밭 없음.
- 못판 제거: 포도 = 기둥 격자 → 이어진 낮은 덩굴 줄(`F_vine_rows`), 올리브 = 엇갈림 격자 + 흔들림(σ 0.18~0.22) + 25% 빠짐 + 크기 0.75~1.2배, 줄기 달린 둥근 나무(`F_olive_trees`).
- 로마 농촌 요소: 구획 경계 생울타리(`F_hedge`, 구슬처럼 이어진 덤불 줄, 띠 옆에만) + 목초지 관목.
- 한계: Workbench 물체 윤곽선(show_object_outline)은 물체 단위라 밭 가장자리에 얇은 선이 남음. 가장자리를 땅속으로 내리는 시도는 땅과 교차해 물결 무늬가 생겨 되돌림.

## 4. [F후보·C4 나무]
- 사이프러스 새 틀: 줄기(-0.3~0.95, 땅속까지) + 둥근 밑동 수관(밑동 z 0.55) → 끝이 뾰족하게 떠서 밭을 뚫던 문제 제거. 밭 띠 위엔 나무 금지.
- 우산소나무: 줄기 짧게(0.78→0.56 높이), 수관 넓고 납작하게 — 막대사탕 → 우산 모양. 틀 5종.
- 리듬: CORE 길 뒤편 4.6 간격 사이프러스 가로수, 아피아 3.2 간격 사이프러스·소나무 교대, 오스티아 3.6 간격 사이프러스; 빈 땅 28곳에 정해 둔 소나무 숲 덩어리(5~8그루 + 가장자리 사이프러스) + 구릉 숲.
  큰 물체는 화면 상자 대신 투영 꼭짓점 점유 격자로 검사(수도교 상자 안 빈 땅에도 심김). 나무 21 → 130그루.

## 5. [C5 해안] 케이크 단면 → 모래사장 비탈
- `terrain_hf.py`·`terrain_mesh2.py`: 해안선에서 -0.95(수면 -0.7 아래) → 26pt 안쪽 0으로 오르는 비탈, 강둑 -0.85 → 9pt 비탈. 땅 옆벽 시작점이 물속이라 단면 벽이 보이지 않음.
- `water_tri.py`: 바다 수면을 땅 밑으로 15pt(강 쪽 제외), 강 수면 6pt 넓힘. 해안 시설 발자국은 비탈을 바다 쪽으로 밀어 밑동이 뜨지 않게.
- `land_tri.py`: 물가 띠(바다 27pt·강 11pt)는 1.45pt 정삼각 격자로 촘촘히 — 처음 쓴 평행 곡선 점은 가는 삼각형을 만들어 cavity가 세로 줄무늬를 그렸음. + 물가 띠 높이 이웃 평균 다듬기 8회.
- `water.py` 파도 띠를 새 물가선(해안 다각형 안쪽 ~8.7pt)에 맞춤(-6.5/-1.5/+5pt).

## 6. [C5 산맥] 탁자 위 바위 → 하나의 산맥
- `terrain_hf.py`: 봉우리 밑동을 잇는 등줄기(SPINE 17점, 세계 좌표 가우스 띠, 진폭 2.3±0.55, 뒤쪽 σ 5.2·앞쪽 σ 3.6) + 직각 가지 능선·골짜기(파장 5.5단위). 글 상자 22pt 둘레·수도교 길 26pt 둘레는 능선 0.
- `a_mtn_merge.py`: 봉우리 8개를 T_land에 합침(원본 물체는 렌더 숨김) → 밑동 윤곽선 사라짐. 봉우리를 능선 위에 걸침(z' = z + 땅높이·(1-z/zmax), 꼭대기 화면 위치 유지 = 헤더 침범 없음), 잘린 원 테두리는 땅속 0.3.
  이 처리 전엔 능선에 묻힌 작은 봉우리가 혹처럼 뚫고 나왔음(왼쪽 위).

## 7. [C1 팔라티노] 지구라트 → 궁전 유적
- `a_palatine.py`: 계단식 상자 3단 삭제 → 둥근 흙 언덕(매끈 음영) + 카메라 쪽 비탈을 깎은 2층 아치 옹벽(Domus Severiana 하부 구조, 아치 구멍 11개) + 언덕 위 무너진 방 벽·반원 벽감·열주 그루터기·창 아치 벽 조각.
  구멍판은 벽 앞 0.09(비스듬한 시선에서 기둥 옆면에 가려 안 보이던 문제 해결). 옛 화면 상자(338.7~401.3 × 1112.7~1170) 그대로.

## 그 밖에 고친 결함
- terrain.py가 만드는 옛 평판 T_ground가 같은 세션 렌더에 남아 z≈0 땅과 z-충돌(맨 위 띠·콜로세움 둘레 유령 선) → a_values.py에서 렌더 전 삭제(기준본에도 있던 결함).
- 밭·나무 배치 시 카메라 뒤·지평선 너머 점이 투영 오류로 화면에 들어오던 것 → 땅 사다리꼴 안 검사.
