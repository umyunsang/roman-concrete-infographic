# 판정 기준 (감독 = 혹독한 비평가)

등급: **AAA**(합격) / AA / A / F. 이름 가린 후보들을 나란히 놓고 같은 기준으로 매긴다.

## 0. 즉시 탈락(F) — 하나라도 있으면
- 감사 0이 아님(글↔물체, 글 배경 복잡, 프레임 밖)
- 글이 가려지거나 읽기 어려움 / 깨진 물체·떠 있는 조각·이음매·유령 도형 / 물체끼리 엉뚱한 충돌
- 고정 조건 위반(색, 글 넣기, 레이아웃 이동, 외부 에셋·크레딧)

## 1. 정보 디자인 (모두 '예'여야 AAA)
- I1 흐름: 포스터를 처음 본 사람이 5초 안에 CORE ①→②→③→④→⑤ 순서를 **길과 방향 신호만으로** 따라갈 수 있는가
- I2 위계: 명도·크기·대비로 콜로세움 > CORE 길 > CORE 작업 장면 > DETAIL 모형 > SUPPORT 장소 > 배경 순으로 눈이 가는가
- I3 글 바탕: 모든 글 아래가 고르고 밝은 바탕인가(APCA 관점에서 대비 충분)
- I4 장면 전달: CORE 장면 다섯 개가 각 공정(채취·혼합·아치 쌓기·보수·연구)을 1초 안에 알아보게 하는가
- I5 DETAIL 모형: 네 원리 모형이 도해로 즉시 읽히는가(절개·단계·화살표 문법 일관)

## 2. 완성도 (모두 '예'여야 AAA)
- C1 로마다움: 길·다리·수도교·밭·나무·유적이 로마 시대 풍경으로 자연스럽게 읽히는가
- C2 일관성: 모든 물체가 같은 클레이 미니어처 문법(면 처리·축척감·두께)으로 보이는가
- C3 깊이: 빛·그림자·명도 단계로 입체감이 살아 있는가(밋밋한 회색판 아님)
- C4 빈틈·반복: 죽은 빈 공간이나 기계적 반복(같은 판 무늬 반복, 못판 같은 점 배열)이 눈에 띄지 않는가
- C5 지형: 산맥·해안·강이 실제 지형처럼 이어져 보이는가(탁자 위 바위·케이크 단면 같은 느낌 없음)

## 등급
- AAA: 0 통과 + I1~I5 + C1~C5 모두 '예'
- AA: 0 통과 + '아니오' 1~2개
- A: 0 통과 + '아니오' 3개 이상
- F: 0 실패
