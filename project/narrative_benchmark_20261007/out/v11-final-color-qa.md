## 판정

**배색 및 시각적 가독성에서 수정 필수 문제 없음. 현 상태 허용 가능.** 전체 포스터와 확대 읽기에서 새로운 색/서체 때문에 생긴 주요 문구 손실, 흰 석회 소실, 코어/보조 위계 전도는 발견하지 않았다. 검토는 시각 QA이며 독자 이해도·실제 인쇄·색약 사용자 검증은 수행하지 않았다. 문구 95개 보존과 형상/배치 보존은 루트의 별도 데이터 검증 대상이다.

## 허용 가능한 한계

1x 전체보기에서 9–10px 수준의 역사·범위 주석은 CORE 헤드보다 작다. 확대본에서 확인 가능한 현재 포스터의 정보 위계이며, 이번 배색으로 흐릿해진 것으로 보이지 않는다. 5번 본문 아래 가장자리에는 옅은 농경지 선이 들어오지만 문자를 가리거나 읽기를 막는 정도는 아니다. 이를 해결하려고 형상/배치를 다시 바꿀 필요는 없다.

## 루트의 최종 텍스트 대비 보강

루트가 텍스트 경계 안의 배경 luminance p10으로 작은 컬러 헤드의 대비를 별도로 점검한 뒤, 텍스트 전용 `type_heat #983821`, `type_calcium #784C26`, `type_water #195B61`로 기존 색상의 명도만 낮추고 `항구` 회전 지명을 본문 잉크로 강화했다. 모형과 번호 색은 유지됐다. 해당 p10 수치는 공식 WCAG 또는 실제 글리프 대비 판정이 아니다.

보강 후 최종 native export의 1x 전체와 코어/바다 디테일, 갱신된 가이드를 직접 확인했다. 2번 제조 헤드·보조 제목, 3번 알갱이 헤드·칼슘 단계 라벨, 4번 물 헤드·균열 보조 제목이 더 짙게 읽히면서 기존 색 역할을 유지한다. 모형·번호·본문의 위계는 변하지 않았다. `항구` 지명과 하단 사례/타임라인은 바다 위에서 읽힌다. 가이드의 텍스트 전용 3색 legend도 잘리거나 다른 설명과 겹치지 않는다. **최종 보강 후에도 추가 수정 필수 문제 없음.**

최종 판정: **현재 v11을 전달해도 되는 색·타이포 조합. 추가 변형안 또는 필수 배색 수정을 권고하지 않음.**
