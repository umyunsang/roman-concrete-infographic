## 항목별 판정 (진행 순서대로 덧붙임)

### 측정 준비
- poster_2x − map_only_2x 차이(RGB 합 > 24)는 글 상자(±3pt) 밖에서 **0픽셀**. 번호 원판·밑줄·이정표·지시선은 모두 배경 렌더에 들어 있고, 글자 마스크에는 Figma 글만 잡힌다.
- 여러 색이 섞인 글(머리말 + 제목)은 열마다 가장 어두운 픽셀 색으로 구간을 나눴다. 렌더 색이 text_spec과 같음을 확인했다(예: 790:180 머리말 #615A4E, 제목 #2E2A22).
- 글자별 배경은 글자 연결 성분(음절) 단위로 halo(2px)의 참 배경 중앙값을 썼다. 1em 칸 단위 값도 함께 봤다.

### E. 인쇄
- **P1·P2 판정 보류.** BRIEF §3-10·STATE R4에 따라 최종 인쇄 원고 단계에서 판정한다. 감점하지 않는다.
- **P3 합격.** text_spec 상자와 재단선 사이 최소 거리는 790:96 오른쪽 20.5pt = 7.23mm다. 실제 잉크 기준 여백도 왼쪽 24.0 / 오른쪽 21.5 / 위 25.5 / 아래 32.0pt로, 최소 7.6mm ≥ 6.35mm(18pt)다.

  - 변환이 실제로 작동함을 확인했다(#00FF00 → #66B329).
  - 글 색 왕복 ΔE00: #2E2A22 **1.03**, #0F4A50 0.47, 나머지 0.00(팔레트가 색역 안). 기준 ≤ 5.
  - 변환 뒤 모든 글의 대표색 쌍 WCAG·Lc가 변환 전과 같다. 기준을 새로 깨는 글은 없다. 790:190 머리말 Lc 58.1은 화면에서 이미 미달인 F-02와 같은 건이라 따로 세지 않는다.
