## 강점(유지할 것)
- 같은 재질 모형 6개의 면 색이 ΔL\* ≤ 1.4로 일치하고, 상자형 모형 모두 윗면 > 왼면 > 오른면으로 주광이 하나로 일관됨.
- 물체 화소 중 L\*<20이 0.085%로 음영이 중간 톤 안에 머물러 클레이 질감이 유지됨(S7).
- 이정표 3개 축척 편차 ≤ 4.6%, 화살표 판 밝은 면 색이 #983821과 ΔE76 ≤ 4, 방향이 읽는 순서와 맞음.
- 현대 물체(h 164~233°, C ≤ 6)와 로마 물체(h 72~83°)의 색 부호가 분명함.
- 강 하류와 바다 색이 같고(ΔE ≈ 0.1) 강 폭이 하류로 14 → 67pt 단조 증가.
- ③ 석회 알갱이 확대 모형과 재료 원리 큐브는 단서 크기·대비가 충분함.
