# 루브릭 · 8 물체 3D 형태·조형 (obj_form)

- 작성: 물체 형태 비평가(2026-10-13, 라운드 10 이미지 r10 기준으로 문턱을 맞춤). 다음 라운드부터 이 문서를 고정해 다른 비평가가 블라인드로 재현한다.
- 범위: 포스터 지도에 놓인 3D 물체(자산) **하나하나의 형태**를 본다. 네 가지를 판정한다. ① 실루엣과 식별(무엇인지 바로 읽히는가) ② 실제 대상과의 형태·비례(로마 시대 실제 장소·건물·도구) ③ 메시 결함 ④ 축척 일관성.
- 판정 단위: **자산**(아래 0.2 자산표의 한 줄). 항목마다 예(합격) / 아니오(불합격) / N/A(해당 없음) / 보류(측정 수단 없음)로 적는다. 보류는 불합격으로 세지 않지만, 무엇이 없어서 못 쟀는지 적는다.
- 등급(BRIEF §6과 같다, **자산 단위**)
  - **AAA** = blocker 0 · major 0 · minor ≤ 2
  - **AA** = blocker 0 · major ≤ 2
  - **A** = blocker 0 · major ≥ 3
  - **B** = blocker 1~2
  - **C** = blocker ≥ 3
  - **분야 등급 = 자산 등급 가운데 가장 낮은 것**이다. 모든 자산이 AAA여야 분야가 AAA다. 보고서에는 자산별 등급 분포도 함께 적는다.
- 수치 기준 표시: 문헌이 직접 준 값은 [문헌값], 문헌 원리를 이 포스터에서 잴 수 있는 값으로 옮긴 것은 [운영값]이다.

## 다른 루브릭과의 경계 (같은 것을 다시 재지 않음)
- 장면 단위 3D 항목(`illustration3d.md`)은 다시 재지 않는다. 대상은 같은 받침 위 인물 키(I3-05), 이정표 3개 축척(I3-06), 아치/인물 비(I3-08), 물체 전체의 접지·그림자(I3-11·12), 물체끼리의 관통·도판 잘림(I3-22), 랜드마크 윤곽 대비(I3-13), 곡면 패싯 개수(I3-03), 원리 모형 단서의 존재·굵기(I3-23·24·26·27)다.
  - 이 루브릭은 같은 현상을 **자산 하나 안**에서 잰다.
  - 곡면 패싯(OBJ_FORM-17)의 면 단차 문턱은 I3-03과 같은 ΔL\* ≥ 5다. 윤곽 대비(OBJ_FORM-06)는 I3-13 기준(ΔL\* ≥ 10 또는 ΔE76 ≥ 25)을 통과해도 합격으로 본다. 두 루브릭이 서로 반대로 판정하는 일은 없다.
- 글과 물체의 겹침·간격(I3-20, LY-01·02, TY-28, HA C6), 이름표-물체 짝(INF-14·18), 사실 문장의 정확성(INF-19·20)은 보지 않는다. 이 루브릭은 **물체의 모양**만 본다.
- 재질 색과 시대 색 부호(CL-08·09·10·12, I3-04), 명도 위계(value.md)는 보지 않는다. 색은 윤곽 분리(06)와 결함 검출에만 쓴다.

## 고정 조건·기존 결정 (감점하지 않음 · 다시 내지 않음)

  - 클레이 미니어처 디오라마와 약간 플랫한 음영(4).
  - 콜로세움 중심의 동심원 배치와 그에 따른 **비균일 축척**: 영웅이 가장 크다(1, I3-07).
  - 이정표의 **화살표 판**은 형태·색 모두 판정하지 않는다(6). 기둥 부분만 본다.
  - 이정표 ①→②의 자리(9, R1).
- 추상화 허용
  - 1′(관람 거리) 아래의 장식이나 정의 특징이 아닌 세부를 뺀 것은 감점하지 않는다. 기둥머리 조각, 기와 낱장, 창틀 등이 해당한다.

- 방위

  - 근거: Grabler 2008의 다중 투시와 랜드마크 강조.
- STATE 기각·보류
  - R3: 나무 그림자, 강 머리.
  - R5: 모형별 그림자 세기·방향, 해수 모형 지시선.

  - R12: ②→③ 화살 머리 가장자리 대비.
  - 위 항목은 다시 내지 않는다.
  - **R11(베수비오 북서 능선 스캔 지느러미 약 17pt)** 은 minor 1건으로만 세고 올리지 않는다. 길이가 20.4pt(= 17 × 1.2)를 넘거나 다른 자리에 새로 생기면 새 근거로 본다.
- STATE 결정은 그대로 전제한다.
  - D11, D15, D28: 금의 폭·모양.
  - D24: 이정표 기둥 색.

  - D32: 새 포장 구간 돌 치수.

### 0.4 마스크와 네 가지 크롭
1. **자산 마스크**
   - 우선 Blender의 물체 마스크(Object Index/Cryptomatte, 같은 카메라)를 쓴다.
   - 없으면 이미지 규칙을 쓴다.
     - 바탕 g = 상자 바깥 6~20pt 고리의 Lab 중앙값.
     - 물체 화소 = ΔE00(화소, g) > 5. 단, 그림자 화소는 뺀다. 그림자 화소는 g와 Oklch 색상각 차 ≤ 6°, 채도 비 0.8~1.25이면서 L\*만 낮은 화소다.
     - 반지름 0.5pt로 닫는다. 상자 안 가장 큰 연결 성분을 본체로 한다.
   - 이웃 지물(길·다리·밭)이 붙으면 상자 경계에서 자르거나 씨앗 점으로 고른다.
   - 지시선·화살표처럼 물체가 아닌 요소는 뺀다.
2. **맥락 크롭**: map_only_2x에서 자산 상자 + 사방 40pt. 글은 없고 이웃 지물은 있다.
3. **단독 크롭**: 마스크 바깥을 바탕 g의 고른 색으로 채우고 여백 20pt를 둔다.
4. **실루엣 크롭**: 구멍을 채운 마스크를 흰 바탕 위 검정으로 칠한다.
5. **시력 제한 크롭**: 단독(또는 맥락) 크롭을 **출력 1 px = 그 자산 관람 거리의 1′** 로 줄인다.
   - 배율 = 1 / (2 × 1′pt): H·C 0.404, L 0.606, D·B·G 0.853.
   - 줄이기 전 가우스 σ = 출력 0.5 px로 거른다(LANCZOS).
   - 근거: 사람은 32×32 컬러 이미지로도 장면을 원본만큼 알아본다. 맥락에서 떼어 낸 작은 물체는 인식률이 크게 떨어진다(O4).

### 0.6 판정자 식별 절차 (OBJ_FORM-01·02·03)
- 판정자 3명. 서로 기록을 공유하지 않는 새 VLM 세션이나 사람으로 한다. VLM은 3D 자산 평가에서 사람 판단과 정렬된다(I3 S15).
- 포스터 전체·글·이름표는 보여 주지 않는다.
- 질문: "이 그림 속 물체는 무엇입니까? 가장 구체적인 이름 하나로 답하세요." **첫 답만** 채점한다.
- 채점 기준
  - 정답 = 자산표 정답어 또는 더 구체적인 이름.
  - 상위어('건물', '탑', '물체', '덩어리')는 오답이다.
  - **결정적 오인** = 다른 기능·시대의 특정 사물 이름이다. 예: 주사위, 드럼통, 이글루, 교회 종탑, 고슴도치, 잎, 못판.
- [문헌값] 문턱
  - ISO 9186-1:2014 이해 기준 = 응답자 ≥ 66%(O2) → 3명 중 2명.
  - ANSI Z535.3 = 정답 ≥ 85% · 결정적 오인 ≤ 5%(O1) → 3명 표본에서는 3명 모두 정답이고 결정적 오인 0명.

### 0.7 색·명도·깊이 보정
- L\*: sRGB → 선형 → Y → CIE L\*(D65).
- ΔE00: Sharma 2005 식(O19), skimage `deltaE_ciede2000`.
- 색상각·채도: Oklch(color.md S11).
- 깊이 축척 s(y): 길 폭(D32에서 같은 치수로 깐 돌)을 y 위치 5곳 이상에서 재어 직선으로 맞춘다.
  - 기울기가 포스터 높이 전체에서 5% 미만이면 s = 1(평행 투영에 가깝다, I3-05 확인)이다.
  - 크기 비교는 측정값 ÷ s(y)로 한다.
- 평면 비례(위에서 본 비)
  - Blender `dimensions` 또는 위에서 본 직교 렌더로 잰다.
  - Blender가 없으면 카메라 고도각이 알려진 경우에만 화면값을 보정한다. 모르면 **보류**다.

### 0.8 집계 규칙
- 결함 후보(자동 검출)는 2x 이미지 **4배 확대**로 눈으로 확인한 것만 센다.
- 같은 원인은 한 지적으로 묶는다. 가장 구체적인 항목 하나에만 센다.
- 두 자산에 걸친 결함은 메시가 결함을 가진 쪽에 넣는다. 모호하면 등급이 높은 자산에 넣는다.
- 심각도는 항목에 적힌 대로 정한다. 항목에 없으면 H·C·L은 한 단계 높은 쪽, D·B·G는 낮은 쪽이다.

## A. 실루엣·식별

**[OBJ_FORM-01] 이름표 없이, 관람 거리 해상도에서 무엇인지 알아보는가?**
- 대상: 모든 자산.
- 측정
  - H·C·L·D·B는 시력 제한 **단독** 크롭을 쓴다.
  - G는 시력 제한 **맥락** 크롭을 쓴다. 작은 일반 지물은 맥락으로 읽히기 때문이다(O4).
  - 0.6 절차로 판정자 3명에게 묻는다.
- 합격: H·C·L은 3/3 정답 [문헌값 ANSI 85%]. D·B·G는 ≥ 2/3 정답 [문헌값 ISO 66%].
- 실패 심각도: H·C·L major / D·B·G minor.
- 근거: O1, O2, O4, O5(Palmer 1981: 정준 시점에서 가장 빨리 이름을 댐), I3 S15.

**[OBJ_FORM-02] 모양으로 정의되는 자산은 실루엣만으로 알아보는가?**
- 대상: 건물·지형·나무·인물 장면·도구.
  - H01, L01~L09, B05~B07, D04~D06, G01~G03.
  - 개념 큐브와 시편(C03·C04·C05·D01·D03·D08)은 일부러 단순한 입체라서 N/A.
- 측정: 실루엣 크롭(원래 해상도)으로 0.6 절차.
- 합격: ≥ 2/3 정답.
- 실패 심각도: H major / 나머지 minor. 실루엣 식별률은 물체마다 0~100%로 크게 갈리므로(O3), 영웅만 major로 둔다.
- 근거: O3, I3 S18(Secord 2011: 실루엣 길이·투영 면적이 좋은 시점의 핵심), O7.

**[OBJ_FORM-03] 다른 사물로 잘못 읽히지 않는가(결정적 오인 0)?**
- 대상: 모든 자산.
- 측정
  - OBJ_FORM-01·02 응답, 그리고 맥락 크롭에 대한 같은 질문의 응답에서 결정적 오인 수를 센다.
  - 점 무늬 큐브(C03·D01, 머리말 B04)는 보조 측정을 한다.
    - 보이는 각 면의 흰 점 지름 변동계수 CV.
    - 원형도(4πA/P²) 중앙값.
    - 점 배열이 주사위 눈 1~6의 격자 대칭 패턴과 같은 면의 수.
- 합격: 결정적 오인 0/3. 점 무늬 큐브는 추가로 CV ≥ 0.30, 원형도 중앙값 ≤ 0.85, 주사위 눈 배열 면 0개 [운영값].
- 실패 심각도: 1/3이면 minor. ≥ 2/3이거나 보조 측정이 2개 이상 실패하면 major(D·B·G는 minor).
- 근거: O1(결정적 오인 ≤ 5%), O43(석회 알갱이 = mm 크기 '밝은 흰 덩이'), O7(규칙적 비우연 속성은 설계된 기호로 읽힘).

**[OBJ_FORM-04] 정의 특징이 가림 없이 보이고 관람 거리에서 해상되는가?**
- 대상: 사실표가 있는 자산.
- 측정: 사실표 '정의 특징' 각각에 대해 세 가지를 잰다.
  - (a) 가려지지 않고 보이는 투영 면적 비.
  - (b) 가장 작은 치수(pt).
  - (c) 전체 크기(pt).
- 합격: (a) ≥ 50%, (b) ≥ 1′, (c) ≥ 5′. 0.3표의 해당 거리 값을 쓴다.
- 실패 심각도
  - 정의 특징이 아예 없으면 OBJ_FORM-08(사실)로 판정한다.
  - 있으나 가려지거나 해상되지 않으면 H·C·L major / D·B·G minor.
- 근거: O9(Snellen: 모양 5′, 세부 1′), O7(부품이 회복 가능해야 인식), O6(전형적 시점이 더 잘 검출됨, 2022).

**[OBJ_FORM-05] 자산이 알아볼 만큼 큰가?**
- 대상: 모든 자산. 인물 장면은 장면 전체로 잰다.
- 측정: 마스크 외접 상자 긴 변(pt)을 관람 거리의 arcmin으로 바꾼다.
- 합격: ≥ 32′ [운영값]. H·C 39.6pt, L 26.4pt, D·B·G 18.8pt.
- 실패 심각도: C major / 나머지 minor.
- 근거: O4(32×32에서 사람 인식 유지, 그 아래 급락), O9.

**[OBJ_FORM-06] 윤곽이 바탕과 갈려 닫힌 모양으로 보이는가?**
- 대상: 모든 자산.
- 측정
  - 마스크 윤곽을 1pt 간격으로 표본한다.
  - 각 점에서 안쪽 1~3pt 띠와 바깥 1~3pt 띠의 중앙값을 비교해 ΔL\*와 ΔE00를 잰다.
  - '잃은 윤곽' = ΔL\* < 5이면서 ΔE00 < 5인 점.
  - 극성(안쪽이 밝음/어두움) 반전 횟수는 참고값으로 적는다.
- 합격
  - 표본의 ≥ 80%가 ΔL\* ≥ 10 또는 ΔE00 ≥ 10.
  - 잃은 윤곽이 한 구간에서 윤곽 길이의 ≤ 10%, 합계 ≤ 20%.
  - 또는 I3-13 기준 통과.
- 실패 심각도: H·L major / 나머지 minor.
- 근거: O8(Elder & Zucker 1993: 닫힌 윤곽은 모양 판별을 빠르게 하고, 모서리의 대비 극성 반전은 그 이득을 없앰), O19, I3-13.

**[OBJ_FORM-07] 특징 면이 카메라 쪽을 향하는가(정준 시점)?**
- 대상: H01, L01, L02, L03, L05, L06, L09, C06~C08, D04~D06.
- 측정
  - Blender: 특징 면(판테온 현관, 콜로세움 바깥 아케이드, 수도교·다리 아치 면, 등대 층계, 가마 아궁이)의 법선과 카메라 시선을 땅에 투영한 사이 각 θ.
  - 이미지: 특징 개구부(아치·문)의 화면 폭/높이 ÷ 실제 폭/높이 = 단축률.
  - 아케이드는 아치 열 축과 시선 사이 각도를 잰다.
- 합격: θ ≤ 60°(단축률 cos θ ≥ 0.5). 아케이드 축과 시선 사이 ≥ 30°(아치가 겹쳐 하나로 보이지 않음). 실제 방위를 따를 필요는 없다.
- 실패 심각도: H·L major / 나머지 minor.
- 근거: O5(정면·옆·위가 함께 보이는 3/4 시점이 가장 좋고 이름도 빨리 댐), O6, I3 S18, O11(다중 투시로 랜드마크 가시성을 높임).

## B. 실제 대상의 형태·비례

**[OBJ_FORM-08] 이름 붙은 실제 대상의 정의 형태가 사실과 맞는가?**
- 대상: 사실표 F1~F25 해당 자산.
- 측정: 사실표의 '정의 특징' 각각이 있음/없음, '모순 형태'가 있음/없음.
  - 맥락 크롭과 4배 확대로 확인한다.
  - 현재 모습/서기 79~80년 모습 둘 다 허용되는 대상(F1, F8)은 한 모습 안에서만 일관성을 본다.
- 합격: 정의 특징 모두 있음, 모순 형태 0.
- 실패 심각도
  - 정의 특징이 없거나 모순 형태가 **5′ 이상으로 보이면 blocker**(BRIEF: 사실 오류).
  - 5′ 미만이면 minor.
  - '권장' 특징만 없으면 minor.
- 근거: 사실표 각 행의 출처, BRIEF §6.

**[OBJ_FORM-09] 핵심 비례가 특징을 살리는 쪽에 있는가?**
- 대상: 사실표에 비례가 있는 자산(F1, F2, F5, F6, F7, F10, F13, F22, F25).
- 측정
  - 모형 비 r을 잰다. 평면 비는 0.7 규약을 따르고, 측정 수단이 없으면 보류다.
  - 특징이 사라지는 중립값 r₀가 있으면 **특징 강도 k = (r − r₀)/(r_실제 − r₀)** 를 구한다.
  - r₀가 없으면 실제값 대비 편차(%)를 구한다.
- 합격: 0.7 ≤ k ≤ 2.0, 또는 편차 ±30% 안 [운영값].
  - 과장은 알아보기를 돕는다. 캐리커처는 실제보다 빨리 알아보고, 반캐리커처는 늦다(O10).
- 실패 심각도
  - k < 0.7 또는 편차 −30% 밖(특징 약화)이면 major.
  - k ≤ 0(역전)이면 OBJ_FORM-08 blocker로 넘긴다.
  - k > 2.0(지나친 과장)이면 minor.
- 근거: O10, O11, 사실표 출처.

**[OBJ_FORM-10] 정의 개수와 반복 리듬이 맞는가?**
- 대상
  - 정의 개수: 콜로세움 아케이드 3층 + attic 1, 판테온 정면 기둥 8.
  - 반복 리듬: 콜로세움 층당 아치, 수도교 아치, 다리 아치, 폼페이 지붕, 밭 이랑.
- 측정
  - 요소 사이 간격이 관람 거리 1′ 이상이면 센다. 1′ 미만이면 N/A다.
  - 반복 간격은 s(y)로 보정한 피치의 변동계수 CV를 잰다.
  - 보이는 아치 수는 80·φ/360과 비교한다.
- 합격: 정의 개수 정확. 비정의 반복 수는 기대값 ±15%, 피치 CV ≤ 10% [운영값].
- 실패 심각도: 정의 개수 오류(해상됨)는 blocker(사실 오류). 비정의 수·피치는 minor.
- 근거: O24(층마다 아치 80, 도리스·이오니아·코린트 + attic 벽기둥), O23, O25(정면 8 + 뒤 4+4).

**[OBJ_FORM-11] 시대 착오 사물·형태가 없는가?**
- 대상
  - 로마 시대로 표시된 모든 자산과 그 안의 인물·도구·소품.
  - 제외: 현대로 표시된 자산(C01, C05, B06, D05의 조사 인물·삼각대), 고정 조건의 이정표 화살표 판.
- 측정: 사실표 '모순 형태'와 아래 목록에 해당하는 요소를 찾는다. 등장 연대가 확인된 것만 센다.
  - 제본 책(코덱스)으로 그린 1세기 이전 저술.
  - 외바퀴 손수레(유럽 1170~1250년).
  - 굴뚝(12세기).
  - 유리 등롱 등대.
  - 근대 4:2:1 벽돌.
  - 철제 파이프·볼트·비계 클램프.
  - 근대 옷차림(바지 작업복·안전모).
- 합격: 0개.
- 실패 심각도: 5′ 이상이고 판정자 ≥ 2/3이 그 사물로 읽으면 **blocker**(사실 오류). 5′ 미만이면 minor.
- 근거: O40, O41, O42, O39, O34, BRIEF 고정 조건 4·6.

**[OBJ_FORM-12] 자산의 시대 상태(온전·미완·폐허)가 그 역할과 맞는가?**
- 대상: 모든 로마 자산.
- 측정
  - 폐허로 그린 자산이 '남은 유적'으로 짜여 있는지 본다. 자산 이름 또는 그 자산을 가리키는 글이 유적·조각·남아 있다·오늘이라고 하는 경우다(예: CORE ① "약 2천 년 된 유적이 남아 있다" ↔ 콜로세움).
  - 시점이 정해진 장면(폼페이 공사현장 79년, ② 반죽, 항구, 가마)은 온전하거나 **미완**이어야 한다.
  - 미완 = 곧은 윗선의 쌓다 만 벽, 재료 더미, 도구 또는 비계. 깨진 윤곽·흩어진 파편은 폐허다.
  - 한 자산 안에서 두 상태가 섞인 경우도 센다.
- 합격: 모든 자산의 상태가 역할과 맞음.
- 실패 심각도: minor. CORE가 가리키는 자산이나 시점이 적힌 장면이 반대 상태면 major.
- 근거: O44(서기 79년 짓다 만 현장 = 미완), O23(바깥 고리 남쪽은 1349년 지진으로 무너짐 → 현재 모습), BRIEF §2.

**[OBJ_FORM-13] 실제 장소끼리의 위치 관계가 맞는가?**
- 대상: L01~L10, D06, 티베르강·해안선.
- 측정: 자산 중심과 경계의 지도 좌표로 아래 관계를 판정한다. 거리는 비균일 축척이므로 순서·인접만 본다.
  - T1 티베르강이 바다로 흘러들고 항구(L06·L07·D07)가 그 하구 곁(하구 ≤ 150pt) [O35].
  - T2 폼페이(L05·D06)가 베수비오 밑동 곁(간격 ≤ 베수비오 밑동 반지름)이고 해안선 곁(≤ 30pt) [O32].
  - T3 베수비오 밑동이 해안선에서 ≤ 밑동 지름 [O31].
  - T4 아펜니노 중심이 콜로세움보다 해안에서 멂 [O37].
  - T5 아피아 가도가 콜로세움에서 베수비오 쪽으로 나감(방향 차 ≤ 60°) [O38].
  - T6 수도교의 먼 끝이 가까운 끝보다 산맥에 가까움 [O28].
  - 방위(참고 판정): 로마→베수비오 남동, 로마→포르투스 남서, 베수비오→폼페이 남동(O31·O35·O38). 반사 없는 회전 하나로 맞췄을 때 각 쌍의 방위 차가 ≤ 90°인지 본다.
- 합격: T1~T6 모두 성립, 방위 차 ≤ 90°.
- 실패 심각도: T 관계가 깨지면 blocker(사실 오류). 방위 차 > 90°만이면 minor. 그림 지도는 배치를 위해 방향을 왜곡하고, 동심원 배치가 고정 조건이기 때문이다.
- 근거: 각 관계의 출처, O11(일반화 연산: 변형·이동), I3 S3(3D 지도는 추상화·일반화).

## C. 메시 결함 (보이는 것만)

**[OBJ_FORM-14] 본체에서 떨어져 떠 있는 조각이 없는가?**
- 대상: 모든 자산.
- 측정
  - 이미지: 마스크의 본체 밖 연결 성분 가운데 세 조건을 모두 갖춘 것을 후보로 잡는다.
    - 면적 ≥ 1pt².
    - 본체와 간격 ≥ 0.5pt.
    - 밑 3pt 안에 접촉 어둠(ΔL\* ≥ 3)이 없음.
  - Blender: 면 수 < 본체의 0.5%이고 본체와 최소 거리 > 바운딩 대각선의 0.2%인 메시 섬 가운데 카메라에 보이는 것.
  - 의도된 분리 요소(물방울, 열 표시, 흰 알갱이, 유적 장면에 놓인 돌)는 뺀다.
- 합격: 확인된 떠 있는 조각 0.
- 실패 심각도: H·C·L major / D·B·G minor.
- 근거: O14(Hi3DEval 2025: 형상 타당성 = 왜곡·떠 있는 부품 없음), O13(고립·매달린 요소), I3 S12(Cooper 2023: 접촉 단서가 '떠 있음' 판단을 좌우), I3-21.

**[OBJ_FORM-15] 구멍·찢김·뒷면 노출이 없는가?**
- 대상: 모든 자산.
- 측정
  - (a) 마스크 안의 닫힌 바탕 영역 가운데 설계된 개구부가 아닌 것(면적 ≥ 1pt²)을 센다. 설계된 개구부(창·아치·오쿨루스·비계 틈)는 solidity ≥ 0.85이고 같은 모양이 2개 이상 반복된다.
  - (b) 표면 안의 어두운 실금을 센다. 주변보다 ΔL\* ≤ −15, 폭 ≤ 1pt, 길이 ≥ 3pt이고, 설계된 금(①④⑤)·부재 이음이 아닌 것이다.
  - Blender: 보이는 면의 경계 모서리 고리가 화면에서 지름 ≥ 1pt.
- 합격: 0.
- 실패 심각도: H·C major, 그리고 정의 특징을 끊는 구멍이면 major / 그 밖 minor.
- 근거: O13(시각화에서 용납 안 되는 것은 의미 있는 구멍), O14, I3 S17(Eval3D 2025).

**[OBJ_FORM-16] 스캔 지느러미·가시·막이 없는가?**
- 대상: 모든 자산. 특히 스캔·생성 자산인 H01, L04, L08, D04, D05.
- 측정
  - 실루엣에서 반지름 1pt 원판으로 열림(opening)을 하고, 남는 돌출 성분 가운데 길이 ≥ 3pt인 것을 후보로 잡는다.
  - 설계된 가는 부품(기둥, 비계, 나무 줄기, 결정 바늘, 창살)은 뺀다.
  - 4배 확대로 안쪽도 본다. 떨어진 두 부분을 잇는 얇은 평평한 '막', 능선 위 실 같은 날이 대상이다.
- 합격: 0. R11 지느러미는 minor 1건으로만 센다.
- 실패 심각도: H·C major / 나머지 minor.
- 근거: O13(실물 디지털화 메시의 잡음·위상 잡음), O14(Hi3DEval 2025: 의도된 세부와 잡음 구분), STATE R11.

**[OBJ_FORM-17] 곡면이 각진 패싯으로 보이지 않는가?**
- 대상: 돔·원통·원뿔·타원 벽·수관·더미가 있는 자산.
  - H01, L01, L04, C05, C06~C08, B01, B02, B06, G01~G03.
- 측정
  - (a) 곡면 윤곽을 맞춤 원·타원과 비교한다. 주기적 꼭짓점에서 생기는 최대 처짐(sagitta)과 꼭짓점 꺾임각을 잰다.
  - (b) 곡면 위 이웃 평면 조각 사이 ΔL\*와 경계 모양(직선 여부)을 본다.
- 합격: (a) 처짐 < 관람 거리 1′이고 주기적 꺾임각 < 10°. (b) 직선 경계로 갈리는 이웃 조각의 ΔL\* < 5(I3-03과 같음).
- 실패 심각도: H·C major / 나머지 minor.
- 근거: O15(Gouraud 1971: 조각 사이 밝기 단절을 없애야 곡면으로 보임, 선형 보간의 기울기 단절은 마하 띠를 만듦), O16(Blender: 평면 음영은 면 경계를 '날카롭고 분명하게' 보이게 함), O9, I3-03.

**[OBJ_FORM-18] 겹친 면의 깜빡임 무늬(z-fighting)가 없는가?**
- 대상: 모든 자산. 특히 판이 겹치는 곳인 기단 고리·길·밭 판·물 표면·받침.
- 측정
  - 이미지: 한 평면 안에서 두 재질 색(서로 ΔE00 ≥ 5)이 물체 모양과 무관한 톱니·줄무늬로 섞인 영역을 찾는다. 3pt 선분 안에서 두 색 사이 전환이 ≥ 3번이고 면적이 ≥ 2pt²인 것이다.
  - Blender: 서로 다른 물체·재질의 거의 같은 평면 면(법선 차 ≤ 1°, 거리 ≤ 장면 깊이 범위의 1e-4)이 화면에서 겹치는 곳.
- 합격: 0.
- 실패 심각도: H·C 또는 글 상자 20pt 안이면 major / 그 밖 minor.
- 근거: O17(거의 같은 깊이의 두 면이 화소를 다투는 렌더 결함, 해결은 면을 떼기), O18(Akeley & Su 2006: 올바른 가림에 필요한 최소 면 간격).

**[OBJ_FORM-19] 자산 안 부품이 제대로 맞붙어 있는가(틈·관통 없음)?**
- 대상: 부품이 있는 자산. 기둥-받침, 지붕-벽, 인물 발-바닥, 도구-손, 판-기둥, 비계-벽.
- 측정: 닿아야 할 부품 사이 보이는 틈과, 연결 없이 다른 부품을 뚫고 나온 길이를 잰다.
- 합격: 틈 < 1′, 관통 < 1′(관람 거리).
- 실패 심각도: minor. CORE 장면의 인물이 떠 있거나 도구가 손·몸을 관통하면 major.
  - 경계: 자산과 바닥·다른 자산 사이 문제는 I3-12·I3-22에서 본다.
- 근거: I3 S12(Cooper 2023), O14(구조 온전성), O13(틈·겹침·교차).

**[OBJ_FORM-20] 음영 이상(뒤집힌 노멀·음영 이음)이 없는가?**
- 대상: 모든 자산.
- 측정
  - (a) 같은 방향·같은 재질의 이웃 면보다 ΔL\* ≥ 15 어둡거나 밝은 고립 조각(≥ 1pt²) 가운데 그림자로 설명되지 않는 것을 센다. 광원 쪽에 가릴 물체가 없어야 한다.
  - (b) 매끈한 곡면 위의 직선 음영 이음(양쪽 ΔL\* ≥ 5, 길이 ≥ 5pt)을 센다.
- 합격: 0.
- 실패 심각도: H·C major / 나머지 minor.
- 근거: O13(일관되지 않은 방향 = 대표 결함), O16, O15.

**[OBJ_FORM-21] 표면 잡음이 형태를 흐리지 않는가?**
- 대상: 모든 자산.
- 측정
  - (a) 마스크 안 고주파 명도 에너지 G를 잰다. 2x 이미지에서 σ = 0.5pt로 다듬은 L\*의 기울기 크기 평균이다. 같은 등급 자산의 중앙값과 비교한다.
  - (b) 온전한 건물(L01, L05, L06, D06)의 곧아야 할 벽 모서리를 본다. 따라 잰 굴곡 진폭이 대상이다.
- 합격: (a) ≤ 2.0 × 중앙값(H는 제외). (b) 굴곡 진폭 < 관람 거리 1′.
- 실패 심각도: minor. 정의 특징의 모서리를 흐리면 major.
- 근거: I3 S4(Semmo 2012: 추상화 수준 일관), I3 S6(Jenny 2013: 과잉 세부는 해석을 흐림), O14(의도된 세부 vs 잡음), O21(Fila 2024: 세부 수준이 식별에 영향), O22(Grammatikaki 2025: 세부·일관성이 인식과 신뢰에 영향).

## D. 축척

**[OBJ_FORM-22] 같은 부류 반복 자산의 크기가 고른가?**
- 대상과 측정
  - 소나무끼리(G01~G03 우산소나무): 수관 폭을 잰다.
  - 다리 2개: 아치 폭을 잰다.
  - 서로 다른 장면의 성인 인물: 키를 잰다.
  - 밭 소품(말뚝·원통): 높이를 잰다.
  - 모든 값은 s(y)로 보정한다.
  - 같은 받침 위 인물(I3-05)과 이정표(I3-06)는 다시 재지 않는다.
- 합격: 최대/최소 ≤ 1.25 [운영값].
- 실패 심각도: minor. CORE 장면 인물과 다른 장면 인물의 비가 > 1.25면 major.
- 근거: I3 S19(Held 2010: 그림 단서가 지각된 크기·축척을 정함), O5(Konkle & Oliva 2011: 물체의 정준 시각 크기는 실제 크기의 로그에 비례 → 같은 부류는 같은 크기로 기대됨), I3 S2.

**[OBJ_FORM-23] 자산 안 부품끼리 축척이 맞는가?**
- 대상: 인물·도구·문·창·계단이 있는 자산(C02, D05, D06, L05, L06, L01).
- 측정: 같은 자산 안 인물 키 h를 기준으로 잰다. 인물이 없으면 같은 자산의 창·문끼리 잰다.
- 합격 [운영값]
  - 삽·괭이 0.6~1.0 h.
  - 삼각대 0.8~1.1 h.
  - 바구니·통 0.2~0.6 h.
  - 계단 한 단 ≤ 0.12 h.
  - 같은 건물의 같은 종류 창·문 크기 CV ≤ 15%.
  - 아치/인물은 I3-08에서 보므로 다시 재지 않는다.
- 실패 심각도: minor. 크기 탓에 다른 사물로 읽히면(OBJ_FORM-03 오인과 같은 원인) major로 하나만 센다.
- 근거: I3 S19, O5.

**[OBJ_FORM-24] 지도 층 건물끼리 실제 크기 순서가 지켜지는가?**
- 대상
  - 지도 층 건물·구조물: L01, L02, L03, L05, L06, L07, L09.
  - 제외: 영웅(I3-07), 이정표(고정 조건 6의 길잡이 기호), 개념 모형(C03·C04·D01·D02·D03·D08), 인물 장면(C02·D05·D06), 머리말, 지형.
- 측정
  - 실제 크기 비 ≥ 2인 쌍만 고른다(사실표·출처 값). 예:
    - 판테온(길이 84 m) > 석회 가마(바닥 지름 약 3 m, 높이 약 6 m).
    - 포르투스 등대(> 100 m 추정) > 판테온 높이(58 m).
    - 폼페이(64~67 ha) > 판테온.
  - 화면 크기(마스크 외접 상자 긴 변 ÷ s(y))의 순서를 본다.
- 합격: 순서가 실제와 같음. 크기 압축은 허용한다. 정준 시각 크기는 실제 크기의 로그에 비례하기 때문이다(O5).
- 실패 심각도: 실제 비 ≥ 4인 쌍이 뒤집히면 major / 2~4인 쌍이 뒤집히면 minor.
- 근거: O5, O11(강조는 일반화로 하되 덜 중요한 건물을 뒤로 물림), O25, O30, O34, O32.

**[OBJ_FORM-25] 이름 붙은 지형의 높이 순서와 수직 과장이 맞는가?**
- 대상: L04 베수비오, L08 아펜니노.
- 측정
  - 밑동~정상의 화면 높이 ÷ s(y)를 잰다.
  - 실제 높이(아펜니노 봉우리 2,000~2,912 m > 베수비오 1,281 m)와 비교한다.
  - 다르면 두 지형의 수직 과장비(화면 높이/실제 높이)의 비를 잰다.
- 합격: 높이 순서가 같거나, 수직 과장비의 비 ≤ 2 [운영값].
- 실패 심각도: minor. 지형은 기호 축척이고 디오라마 표현은 고정 조건 4다.
- 근거: O31, O37, I3 S3(3D 지도는 사실 재현이 아니라 추상화·일반화).

## E. 개념 모형·인물의 형태

**[OBJ_FORM-26] 비교 모형은 변수 말고 형태가 같은가(통제된 비교)?**
- 대상: C04 ④ 큐브 3개, C05 ⑤ 시편 2개, B01·B02 생석회·화산재 더미.
- 측정: 단독 마스크로 다섯 가지를 잰다.
  - 외접 상자 폭·높이.
  - 윗면 모서리 길이.
  - 모서리 둥글림 반지름.
  - 놓인 방향(윗면 모서리 각).
  - 받침과의 관계.
- 합격: 크기 차 ≤ 3%, 방향 차 ≤ 3°, 모서리 처리 같음. 서로 다른 점은 단계·조건 단서(금, 물, 흰 메움, 흰 알갱이 유무)뿐이다 [운영값].
- 실패 심각도: C04·C05 major / B01·B02 minor.
- 근거: O12(Tufte의 작은 배수: 일관된 틀이 '데이터의 변화'에 눈을 모음), O43(대조 시편: 생석회 없는 시편은 계속 샘), STATE D11·D28.

**[OBJ_FORM-27] 개념 단서의 모양이 그 개념과 맞는가?**
- 대상: C03, C04, C05, D01, D03, B04.
- 측정
  - (a) 석회 알갱이: OBJ_FORM-03 보조 측정과 같은 값(CV, 원형도, 주사위 배열)을 쓰되 여기서는 '개념 일치'로 본다. 지름 범위는 큐브 한 변의 1~10%. 둘 중 한 항목에서만 센다.
  - (b) 금: 한 줄로 이어짐(끊김 < 1′), 지그재그·가지가 바깥 면에서 시작한다. 폭은 D15·D28로 정해졌으므로 재지 않는다.
  - (c) 해수 결정: 결정 밑동이 큐브 표면에 붙어 있다(떠 있지 않음). 바닷물 면이 큐브를 적신다.
- 합격: 해당 조건 모두.
- 실패 심각도: C major / D·B minor.
- 근거: O43(석회 알갱이 = mm 크기 밝은 흰 덩이, 금이 알갱이를 지나가고 물이 칼슘을 녹여 메움), STATE D4·D15·D28.

**[OBJ_FORM-28] 인물의 몸 비례·복식이 읽히는가?**
- 대상: C02, D05, D06의 인물.
- 측정
  - 머리(턱~정수리)/키를 잰다.
  - 실루엣에서 몸통과 팔·다리가 갈라지는 오목점 수를 센다.
  - 로마 장면 인물의 옷이 무릎 길이 튜닉 계열인지 본다.
- 합격: 머리/키 1/5~1/8.5(고전 규준 1/8 둘레의 양식화 허용) [운영값]. 오목점 ≥ 4. 로마 장면 복식이 시대와 맞는다(현대 복식이면 OBJ_FORM-11로 판정).
- 실패 심각도: minor.
- 근거: O45(턱~정수리 = 키의 1/8, 비트루비우스 비례를 레오나르도가 주석), I3-29(동작 판독은 그쪽에서).

## 참고 구현 (이미지 경로 · 재현용)
- r10에서 시험 실행했다. 판테온은 윤곽 대비 충족 100%, 본체 밖 성분 0, 지느러미 후보 0이 나왔다.
- 이웃 지물이 붙는 자산(등대-돌길)은 상자 경계에서 잘라야 한다.

```python
# uv run --no-project --with pillow --with numpy --with scipy --with scikit-image python -I ref.py map_only_2x.png x0 y0 x1 y1 d_m out
import sys, numpy as np
from PIL import Image, ImageFilter
from scipy import ndimage as ndi
from skimage import color, morphology, measure
Image.MAX_IMAGE_PIXELS = None; S = 2
ARCMIN_PT = lambda d_m: float(d_m * 1000 * np.tan(np.radians(1/60)) / 0.352778)
def load(src, x0, y0, x1, y1, m=20):
    im = np.asarray(Image.open(src).convert('RGB')).astype(float) / 255; H, W, _ = im.shape
    X0, Y0, X1, Y1 = int(max(0,(x0-m)*S)), int(max(0,(y0-m)*S)), int(min(W,(x1+m)*S)), int(min(H,(y1+m)*S))
    yy, xx = np.mgrid[Y0:Y1, X0:X1] / S
    d = np.hypot(np.maximum(np.maximum(x0-xx, xx-x1), 0), np.maximum(np.maximum(y0-yy, yy-y1), 0))
    return im[Y0:Y1, X0:X1], d
def asset_mask(rgb, d):                       # 0.4-1 이미지 규칙
    lab = color.rgb2lab(rgb); g = np.median(lab[(d >= 6) & (d <= 20)], axis=0)
    dE = color.deltaE_ciede2000(lab, np.broadcast_to(g, lab.shape))
    C, Cg = np.hypot(lab[...,1], lab[...,2]), np.hypot(g[1], g[2])
    dh = np.abs((np.degrees(np.arctan2(lab[...,2], lab[...,1]) - np.arctan2(g[2], g[1])) + 180) % 360 - 180)
    shadow = (dh <= 6) & (C/Cg > 0.8) & (C/Cg < 1.25) & (lab[...,0] < g[0])
    obj = morphology.binary_closing((dE > 5) & ~shadow, morphology.disk(1)); lbl = measure.label(obj, connectivity=2)
    ids, cnt = np.unique(lbl[(d == 0) & obj], return_counts=True); return lab, g, lbl == ids[np.argmax(cnt)]
def acuity_crop(rgb, mask, g_rgb, d_m):       # 0.4-5 출력 1px = 1′
    s = 1.0 / (S * ARCMIN_PT(d_m)); comp = np.where(mask[..., None], rgb, g_rgb)
    im = Image.fromarray((comp*255).astype(np.uint8)).filter(ImageFilter.GaussianBlur(0.5/s))
    return im.resize((max(1, round(im.width*s)), max(1, round(im.height*s))), Image.LANCZOS)
def fins(mask, min_len_pt=3):                 # OBJ_FORM-16 후보: 반지름 1pt 열림의 잔여
    f = ndi.binary_fill_holes(mask); r = f & ~morphology.binary_opening(f, morphology.disk(2))
    return [p for p in measure.regionprops(measure.label(r, connectivity=2)) if p.major_axis_length/S >= min_len_pt]
```
