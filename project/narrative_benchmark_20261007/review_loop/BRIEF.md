# 심사 지침서 · 로마 콘크리트 A2 인포그래픽 포스터

## 1. 작품
- 대학 인포그래픽 디자인 수업 과제. **A2 세로(420×594mm) 인쇄 포스터**, 가까이 서서 읽는 전시용(관람 거리 약 0.5~1.5m).
- 원본: Figma 프레임 1191×1684pt(1pt = 1px = 약 0.353mm). 배경 지도 = Blender 3D 렌더 이미지, 글 80개 = Figma 편집형 글.
- 주제·핵심 질문(교수 확정): "로마 콘크리트는 어떻게 약 2천 년을 버텼나?" → 포스터 질문 "철근도 없는 로마 건축물이 어떻게 2천 년을 버텼을까?"

## 2. 정보 역할(교수 지정 구조)
- **CORE ①~⑤**: 질문에 직접 답하는 서사 연쇄. ① 철근이 있어도 금은 생기는데(위 가운데) → ② 물을 넣자, 열이 났다(왼쪽) → ③ 잘못 섞인 걸까? 흰 알갱이의 반전 / ④ 금에 스민 물, 칼슘을 옮기다(아래 가운데, 나란히) → ⑤ 정말 메워질까? 금을 내어 봤더니(오른쪽). 콜로세움 둘레를 반시계로 돈다.
- **BASIC**: 맨 위 '전제 · 로마 콘크리트란?'(왼쪽), '전제 · 어떻게 알았나'(오른쪽).
- **DETAIL**: 원리 모형+짧은 설명(재료 원리·해수 속 새 결정, 제작 원리·열과 석회, 철근 없이 버틴 구조, 균열 원리·금이 메워지는 순서, 석회 알갱이 확대 개념 모형).
- **SUPPORT**: 사례·근거(오늘의 실험실, 프리베르눔 성벽 조각, 로마 항구 방파제 조각, 폼페이 공사현장(79년), 유적 관찰 장면).

## 3. 고정 조건 — 이것 자체를 감점·차단 사유로 쓰지 말 것
교수 지침이나 사용자 결정으로 확정된 것이다. 이 틀 안에서의 품질은 얼마든지 비판해도 된다.
1. 콜로세움을 중심에 둔 **동심원 배치**: CORE는 콜로세움 가까이, DETAIL은 더 바깥(교수 피드백).
2. 부가 설명은 **2줄 안팎**으로 짧게(교수 피드백). 글을 크게 늘리는 해법은 쓸 수 없다.
3. **글 각도 최소화**: 떠 있는 글은 모두 수평. 기운 글은 땅에 눕힌 지명(±30°, 땅 축)뿐(교수 피드백).
4. 지도는 **로마 시대 실제 장소**(아펜니노 산맥·티베르강·티레니아해·베수비오·폼페이·아피아 가도·수도교)를 담은 **클레이 미니어처 디오라마 3D 렌더**(약간 플랫한 음영). 2D 일러스트로 바꾸는 해법은 쓸 수 없다.
5. CORE ①~⑤의 번호 원판·밑줄·제목 둘째 줄은 **모두 같은 ②번 색 #983821**(사용자가 일부러 통일).
6. 읽는 방향 표시는 **로마 가도 이정표 3개**(석회암 기둥 + ②색 화살표 판). 평면 화살표 기호로 되돌리는 해법은 쓸 수 없다. 지도 위 안내 요소는 로마 시대 사물로 만든다는 원칙.
7. 맨 아래 연표는 사용자가 지웠다. **소제목 뒤 배경판은 사용자가 취소**했다(제안 금지).
8. 표·격자형 레이아웃은 쓰지 않는다. 글꼴은 Noto Serif KR(제목) + Noto Sans KR(나머지).
9. ①→② 이정표 자리는 사용자가 지정했다(산기슭, 길에서 떨어짐).
10. 인쇄 해상도·재단 여분은 최종 인쇄 원고 단계에서 판정한다(STATE.md R4). 심사 이미지는 화면 검토용 2배 내보내기다.

## 4. 고칠 수 있는 것(수정 수단)
- Figma: 글의 크기·굵기·행간·자간·색(변수)·위치·줄바꿈·정렬, 낱말 다듬기(사실 의미 유지).
- Blender: 3D 물체의 위치·크기·회전·재질 색, 작은 물체 추가·삭제, 조명·그림자·노출·렌더 설정, 지형·길·물 표현.
- 해법은 **수치로**(pt 좌표, pt 크기, hex, 배율) 제시한다.

## 6. 심사 규칙
- **눈대중이 아니라 측정으로.** 위치·간격은 pt 좌표로, 크기는 text_spec 값으로, 대비는 실제 픽셀(타일에서 글자 가장 어두운 부분과 바로 뒤 배경)로 잰다. 이미지에서 확인하지 않은 상태를 단정하지 않는다.
- 한국어 **줄바꿈 오독**을 본다: 앞 줄 끝 낱말이 다른 뜻으로 먼저 읽히는 끊기(예: '보통 / 온도').
- 지적마다 심각도: **blocker**(객관적으로 증명되는 결함 — 가림·겹침·판독 불가·사실/의미 오류·기준 수치 미달), **major**(분명한 품질 저하, 근거 문헌 있음), **minor**(다듬기).
- 등급: **AAA** = blocker 0 · major 0 · minor ≤ 2 / **AA** = blocker 0 · major ≤ 2 / **A** = blocker 0 · major ≥ 3 / **B** = blocker 1~2 / **C** = blocker ≥ 3.
- 같은 지적을 여러 개로 쪼개 부풀리지 않는다. 취향은 minor 이하. 고정 조건 위반을 요구하는 해법은 내지 않는다.
- 진행 중 결론은 자기 리포트 파일에 항목마다 바로 덧붙인다(세션이 끊겨도 남도록).
