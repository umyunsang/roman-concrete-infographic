# 로마 콘크리트 v10 배색 검토

검토일: 2026-10-08. 실제 기준은 `out/figma_poster_v10_composition_1x.png`다. 이 문서는 추천과 제작 규칙이며, Figma/Blender 캔버스는 수정하지 않았다. 사용한 지침은 `.agents/skills/brand/references/color-palette-management.md`, `typography-specifications.md`, `.agents/skills/design-system/SKILL.md`다. 웹 자료는 사용하지 않았다.

## 현재 포스터에서 배색으로 해결할 부분

큰 콜로세움과 흰 석회 알갱이, 물·결정 과정, 작고 많은 주변 유적이 현재 같은 회색 명도 체계에 속한다. 제목은 매우 짙고 콜로세움은 넓고 밝다. 색을 입힐 때 주변 유적까지 동등하게 강조하면 중심의 주종 관계가 줄어든다. 지도 면적이 크기 때문에 지형·산·농경지를 모두 진하게 칠하는 것도 글 주변을 복잡하게 만들 수 있다. 이는 이미지 관찰과 디자인 판단이다. 독자의 이해도나 체류 시간은 측정하지 않았다.

## 두 방향 비교

| 방향 | 인상과 역할 | 장점 | 조정해야 할 점 |
|---|---|---|---|
| A. 석회·트래버틴 + 청록 + 적갈색 | 따뜻한 유물 지도에 현대 골조·물·발열의 색을 분리 | 로마 건축물의 재료 느낌과 제조 서사를 연결할 수 있다. 콜로세움을 따뜻한 중심으로 두고 차가운 현대 골조와 물을 구분할 수 있다. | 흰 석회가 밝은 지형에 묻히지 않게 어두운 시편에 붙여야 한다. 바다 색이 지나치게 진해지면 하단이 중심보다 먼저 보일 수 있다. |
| B. 밝은 중성 바탕 + 황토 + 해군색 + 주홍 | 도록과 과학 실험의 단정한 대비 | 현대 골조·연구 모형을 명확히 구분하기 쉽다. | 금빛 콜로세움과 해군색 모형이 함께 강해질 수 있고, A보다 로마의 토질·석회 재료감이 약하다. |

**A를 추천한다.** 지형을 한 색으로 착색하는 방식 대신 소재와 설명 기능에 따라 분리한다. 채도는 코어 모형과 최소한의 번호·선에 집중한다. 95개 문구와 현재 구도는 유지한다.

그림자·하이라이트는 기존 3D 조명을 사용한다. 팔레트 색은 화면 기준 sRGB 목표다. Blender 입력에서 색 공간 변환을 고려하고 **렌더된 결과**에서 확인해야 한다. 평면 Hex를 그대로 썼다고 렌더 표면 색까지 같다는 뜻은 아니다.

## 번호·선·타이포의 색 연결

- 1번 현대 대비와 5번 실험: `#365864`.
- 2번 발열: `#B44327`.
- 3번 흰 알갱이: `#8C5B2F`.
- 4번 물과 충전: `#206D74`.
- 번호 글자는 `#FFF4DD`; 밑줄이나 짧은 연결선은 해당 단계의 어두운 강조색.
- 헤드 전체를 밝은 강조색으로 칠하지 않는다. 모든 CORE 헤드와 본문은 짙은 잉크 체계를 유지하고, 필요하면 기존 한두 단어만 해당 단계의 어두운 색을 사용한다. 해당 단어만 바꾸어도 문구는 그대로다.
- 현재 Noto Sans KR Bold/Regular/Medium과 위계는 안정적인 기반이다. 배색을 검토하는 단계에서 본문에 가는 서체나 장식 서체를 추가할 필요는 없다. 제목 서체 변경은 별도 가용 폰트와 동일 폭·높이 검증 후 결정한다.

## 색 면적과 강도

제작 목표의 대략적 비중은 밝은 중성 지형/바탕 62%, 따뜻한 돌 건물/도로 22%, 물·식생 10%, 현대·발열·시편·강조 6%다. 이는 **측정한 현재 픽셀 비율이 아닌 제작 목표**다. 조명에 따른 하이라이트·그림자는 같은 계열로 본다.

중앙 콜로세움 > 제조·시편·균열 모형 > 주변 유적/경관 순으로 채도·색 대비를 둔다. 하단의 큰 화산과 바다에는 가장 진한 강조색을 쓰지 않는다. 산과 농경지는 텍스트와 접하는 곳에서 밝게 유지한다. 단순 단색 tint보다 소재 구분과 따뜻함/차가움의 두 축을 사용한다.

## 제작 확인 수치와 작은 조정 범위

다음은 flat-color 쌍의 sRGB 상대휘도 계산이다. 실제 렌더/글자 대비 인증은 아니다.

| 조합 | 대비 |
|---|---:|
| 헤드 `#2E2A22` / 바탕 `#F3E8D4` | 11.77:1 |
| 본문 `#3E3A31` / 바탕 | 9.33:1 |
| 보조 `#615A4E` / 지형 `#E5D5B9` | 4.72:1 |
| 흰 석회 `#FFF4DD` / 시편 `#97614B` | 4.66:1 |
| 흰 번호 / 1·5 `#365864` | 7.03:1 |
| 흰 번호 / 2 `#B44327` | 5.10:1 |
| 흰 번호 / 3 `#8C5B2F` | 5.27:1 |
| 흰 번호 / 4 `#206D74` | 5.49:1 |
| 본문 `#3E3A31` / 바다 `#82B9BC` | 5.18:1 |

최종 네이티브 포스터 1x/2x에서 확인할 것: 흰 알갱이가 개별 형태로 보이는지, 본문 뒤에 과하게 진한 농경지/수로/그림자가 들어오지 않는지, 3개 균열 모형에서 물·칼슘·결정 역할이 글과 함께 구분되는지, 바다·화산의 색 무게가 콜로세움을 가리지 않는지. 렌더를 보고 시편 모재의 명도를 약 5–8% 낮추거나 밝은 지형을 약 3–5% 올리는 범위가 우선이다. 새로운 색을 추가하는 방식은 피한다.
