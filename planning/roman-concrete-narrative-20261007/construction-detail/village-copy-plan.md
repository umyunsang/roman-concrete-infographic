# Phase 15 — 마을 장면으로 옮기는 정보 계획

2026-10-08. copy/narrative_v13.json, 실제 v14 텍스트·포스터 QA, v11 마을 배치용 inventory를 기준으로 작성. **이 문서만 작성하며 Figma/Blender 생산 파일은 변경하지 않음.** 신규 모델이 아직 생성 중이므로 아래 공간은 배치 원칙이며 확정 좌표가 아니다. 기존 근거 범위 안에서 제안하며 새 연구·역사 주장을 추가하지 않는다.

## 유지할 중심 서사

질문: **철근도 없는 로마 건축물이 어떻게 2천 년을 버텼을까?**

CORE 1–5의 순서는 현대와 로마 비교 → 뜨거운 배합 → 흰 알갱이의 반전 → 물과 칼슘 이동 → 현대 재현 실험이다. 제목·본문·근거 범위를 유지한다. 본문은 Noto Sans KR Regular 11.5/15.5, 0% tracking, 현재 폭 174/160/190/178/180 px와 **2/3/2/2/3줄**을 유지한다. 마을 생활 라벨이 별도의 번호 서사를 만들지 않게 한다.

| CORE | 유지 본문 — 줄바꿈 그대로 |
|---|---|
| 1 | 로마에는 2천 년 전 유구가 남았다.<br>철근 없이, 어떤 재료로 굳혔을까? |
| 2 | 생석회·화산재를 마른 채 섞고,<br>물을 붓자 열이 났다.<br>굳은 반죽엔 흰 알갱이가 남았다. |
| 3 | 불량 혼합으로 여긴 흰 알갱이.<br>연구가 찾은 건 ‘칼슘 공급원’. |
| 4 | 물이 칼슘을 녹여 틈으로 옮긴다.<br>새 결정이 자라 작은 금을 메운다. |
| 5 | 현대 재현 시편에 약 0.5mm 금.<br>생석회 든 쪽은 수 주 뒤 거의 안 샜다.<br>없는 쪽은 계속 샜다. |

CORE 1의 2줄 비교(현대: 포틀랜드 시멘트·철근 보강 / 로마: 석회·화산재), CORE 5의 현대 시편·약0.5mm·수 주·비교군은 유지한다. 이 서사를 “콜로세움 전체가 자가치유해서 2천 년을 버텼다”로 닫지 않는다. 실제 역사 타임라인의 지진·보수 정보도 유지한다.

## DETAIL 3/4 — 실제 크기의 벽·잔해에 연결

지도에 거대한 흰 구체, 알갱이 시편 큐브, 3단계 균열 큐브, 작은 단면 전시 큐브를 남기지 않는다. 자연스러운 재료 더미·작업장·벽체가 장면을 맡고, 기작은 작은 오버레이 정보가 맡는다. 기존 ‘확대’ 제목은 삭제하여 별도 전시물을 요구하지 않게 한다.

**DETAIL 3 — 굳은 모르타르 조각/벽체에 짧은 리더 1개**

```text
굳은 반죽 속 흰 석회 알갱이.
칼슘이 풍부하고 물에 녹아 나온다.
```

Noto Sans KR Regular 9.5/13.5, 폭155~170 px, 2줄 높이27 px. 별도 제목/흰 구체/입체 단면은 추가하지 않는다. 대상은 작업장에 자연스럽게 놓인 **굳은 모르타르 잔해나 벽 속 작은 흰 알갱이**다. 원료 더미의 흰 생석회 가루를 굳은 콘크리트 속 석회 알갱이로 지칭하지 않는다. 원료 더미는 ‘생석회·골재’ 등의 재료 맥락에만 쓴다.

**DETAIL 4 — 작업장 벽체의 작은 금과 빗물 자국에 연결**

```text
물에 녹은 칼슘이 틈으로 이동.
탄산칼슘 결정이 작은 금을 메운다.
```

Noto Sans KR Regular 9.5~10/13.5~14, 폭174~190 px, 2줄. 작은 금·젖은 자국·국부 흰 충전 흔적만 실제 벽 표면에 적용한다. 맨눈으로 보이는 장면은 기작의 설명용 재구성이며, 새로 만든 벽의 재질이나 자가치유가 실측됐다는 의미가 아니다. 특히 **리더를 중앙 콜로세움 벽에 직접 연결하지 않는다.**

CORE 4/DETAIL 4에 바로 인접한 곳에 다음 2줄 근거 범위를 한 번만 유지한다:

```text
다른 유적·재현 시편에서 확인
콜로세움에서 직접 입증 안 됨
```

이 문구를 마을의 먼 하단이나 일반 출처 칸으로 보내지 않는다. DETAIL 3과4를 함께 묶는 경우에는 두 정보 사이/아래에 한 번 두어 공동 범위가 읽히게 한다. 프리베르눔이라는 장소명은 기존 해당 사례 그룹에 유지하며, 새 일반 작업장 벽에 옮겨 붙이지 않는다. 해양 방파제의 새 결정 설명도 이 탄산칼슘 경로와 섞지 않는다.

## 생활·시공 장면용 한 줄 라벨과 2줄 정보

| 장면 | 한 줄 문맥 라벨 | 필요할 때 사용할 2줄 정보 | 기본 표시 |
|---|---|---|---|
| 주거 군집 | **주거와 골목** | 집들이 골목을 따라 모이고,<br>사람들이 그 사이를 오간다. | 군집당 라벨1개만. 본문 비표시. |
| 장터 군집 | **장터와 사람들** | 가게와 좌판 곁으로 모여<br>물건을 옮기고 거래하는 장면. | 군집당 라벨1개만. 본문 비표시. |
| 배합 작업장 | **콘크리트 작업장** | 생석회·화산재를 섞고,<br>물을 더해 반죽을 만든다. | 라벨만. 이미 CORE 2가 3줄로 설명하므로 별도 본문 비표시. |
| 콜로세움의 비계·작업자 | **콜로세움 회랑 시공** | 돌·벽돌·콘크리트를 함께 써<br>기초와 회랑의 볼트를 만든다. | 라벨1개 + 2줄 정보1개. 실제 시공 부위 근처에 묶음. |

주거/장터의 문장은 역사적 발굴 결과가 아니라 그려질 생활 장면의 설명이다. 기본안에서는 이 두 본문을 숨겨 새 정보 상자4개가 생기지 않게 한다. CORE 2에서 이미 설명하는 배합법도 반복하지 않는다. COL 정보는 석재·벽돌·콘크리트의 혼합 구조를 설명하며, 외곽 돌 아치 전체가 콘크리트라는 의미로 쓰지 않는다. 중앙 아레나 바닥을 콘크리트 볼트와 동일시하지 않는다.

한 줄 문맥 라벨은9.5~10 px, 13~14 px line-height, 작은 흙색/중성색으로 한다. CORE 제목 크기나 별도 번호를 사용하지 않는다. 주택 하나마다/작업자 한 명마다 라벨을 달지 않는다. 사람의 걷기·운반·거래 동작은 장면 자체로 전달한다. 일반 생활 군집과 시공 비계는 CORE3/4의 화학적 실증 사례로 분류하지 않는다.

지도 설명의 눈에 덜 띄는 한 곳에 공통 맥락 **‘건축·생활 장면 재구성’** 한 줄을 권장한다. 현재 유구·고대 건설·현대 연구가 함께 쓰인 설명 지도이므로, 새 마을의 정확한 고대 배치나 콜로세움의 특정 공사 연대를 복원했다고 읽히지 않게 한다. 이 라벨은 지도 속 전시 모형을 뜻하지 않는다.

## 기존 정보의 제거/이동

- 거대 구체와 큐브를 가리키던 ‘석회 알갱이 확대’, ‘흰 알갱이가 남은 콘크리트’, ‘틈 속 탄산칼슘 결정’ 리더/라벨은 기존 좌표에 남기지 않는다. 필요한 알갱이·결정 설명은 위 DETAIL 3/4의 2줄에 통합한다.
- 3개 큐브 아래 ‘물이 스밈 / 칼슘 이동 / 결정 충전’은 제거한다. CORE 4 본문과 DETAIL 4가 같은 순서를 짧게 보존한다. 3개의 새 입체 장면이나 떠 있는 도식은 만들지 않는다.
- 도로 행렬 캡션 ‘재료 운반 / 목재 틀 위에 타설 / 돌·모르타르 시공 / 중앙으로 운반 / 굳은 회랑 볼트’와 연속 공정 화살표는 마을 전체를 감는 순서도로 유지하지 않는다. 비계와 작업자가 콜로세움에 실제로 붙은 시공 군집에 위 라벨/2줄을 한 번 붙인다.
- 기존 ‘배합부터 콜로세움까지’ 및 그2줄은 CORE 2와 새 COL 시공 정보에 통합한다. 도로 위 설명을 새 생활 골목의 벽·지붕·보행자에 반복하지 않는다.
- 현재 현대 실험실 설명이 CORE 5 본문과 중복되면 ‘오늘의 재현 실험’ 한 줄 맥락만 남기는 것을 권장한다. CORE 5의 시편과 비교군 조건은 반드시 보존한다. 현장 모습만으로 고대 시공자의 실험이나 로마의 실험실로 오해하게 하지 않는다.
- 폼페이 원료 더미, 프리베르눔 성벽, 해양 방파제 및80년 개장·지진·보수 타임라인은 기존 SUPPORT/근거/역사 그룹에 유지한다. 생활 주택을 새로운 자가치유 실증 사례로 추가하지 않는다.

## 공간·후속 QA 기준

큰 과학 모형이 차지하던 대략 y1135~1405를 주거·작업장·사람에게 돌려준다. DETAIL 3/4의 작은 정보는 각각 현재 CORE 3/4 본문 가까이에 묶거나 실제 벽의 낮은 빈 여백에 둔다. 지붕이나 비계 위에 얹지 않는다. 군집 사이 골목과 사람의 동작이 먼저 읽히고, 그 다음 짧은 라벨이 읽히게 한다. 2줄 정보가 붙는 벽체는 콜로세움의 거대한 외벽보다 작은 작업장/잔해를 우선한다. 정확한 좌표와 카드 폭은 새 모델의 실제 투영 범위로 결정한다.

마지막 native QA는 CORE2/3/2/2/3 유지, DETAIL 각2줄, 입증 한계의 인접성, 원료와 굳은 석회 알갱이의 구분, 일반 마을과 실증 유적의 구분, 건설/아레나 재료 구분, 비계·인물·지붕과 텍스트의 중첩을 확인한다. 새 폰트 설치/다운로드와 추가 역사 연구는 이 계획에 필요하지 않았다.
