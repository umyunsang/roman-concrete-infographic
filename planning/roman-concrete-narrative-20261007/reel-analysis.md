# Reel 분석 근거

대상: https://www.instagram.com/reels/Dcixubzs60u/ — 2tan_saeng. Aside CLI로 대상 탭을 열고 DOM에서 shortcode가 일치하는 media를 확인한 후 로컬 MP4를 확보했다. 본문/영상 장면은 분석 목적의 요약으로 기록하며 전체 자막을 재배포하지 않는다.

## 직접 관찰
- 약71.12초, 로컬 rendition720×1280/30fps, 오디오 스트림 있음. 브라우저1440×2560 DASH와 동일 target shortcode.
- 142개 반초 간격 프레임, 한국어 Apple Vision OCR, 전체71개 1초 간격 contact sheet3장 육안 검토.
- 장면 경계 검출(차이 threshold0.24) 후보: 6.13,9.13,14.23,18.77,23.07,29.40,37.40,39.93,52.57,54.00,55.57,57.10,64.07,67.60. 후보일 뿐 모든컷/동작의 완전한 집계가 아니다.
- Instagram페이지에 AI콘텐츠 표기. 장면은 렌더/생성된 설명 그림으로 관찰됐고 실험사진으로 쓰면 안 된다.
- 로컬ASR 27개 구간(0~70.96초)을 프레임 자막과 대조했다. 음성은 작은 자막 조각을 완결문으로 이어준다. 음색/BGM/효과음 평가는 수행하지 않았다.

## 전달 장치의 해석
- 한 번에 주요물체 하나와 짧은 자막만 제시해 다음정보를 고르는 부담을 영상이 대신한다.
- 건물전체→배합→흰알갱이→균열내부로 크기를 바꾸며 깊어진질문에 답한다.
- 작은단위로 변화를 계속 주지만 대상의연속성을 유지해 작업기억부담을 줄이는 것으로 해석된다. 실제시선추적이나시청유지율을 확보한것은 아니다.
- 재료목록보다 반응의동사와 결과를 오래 보여준다.39.93–52.57초 약12.64초가 핵심 균열행동 시퀀스다.
- X표시·화살표·프레이밍·밝은알갱이·전경단면이 설명대상을 직접 지정한다. 그레이포스터에는 명도·선굵기·확대크기·연결선으로 이식 가능하다.
- 짧은자막은 영상/음성 맥락 덕분에 성립한다. 정적화면에 조사없는 단어만 복사하면 연결관계가 사라지므로 짧은 완결문/동사캡션으로 재작성해야 한다.

## 이식하지 않을 주장
- 보편적현대수명100년 대 고대수명2000년, 모든배합이바닷물, 의도적설계를입증했다는 단정, 현대실험누수감소를구조강도회복과동일시하기.
- 불꽃/발광/피부비유는 관심장치이지만 화학반응의관찰증거가 아니다.

## 영상 내용 요약 교정
- 초반의 일부 프레임만 읽었을 때 '철근 하나 없이'를 균열 없다는 뜻으로 잘못 요약했다. ASR0~70.96초와 원프레임을 대조해 교정했다. 영상은 무균열을 직접 말하지 않는다. 모든 손상을 스스로 고친다는 확대 표현과 보편수명 비교는 별도 과학검증 대상이다.
