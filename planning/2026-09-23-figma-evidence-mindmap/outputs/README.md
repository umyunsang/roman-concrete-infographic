# 로마 건축물은 어떻게 약 2천 년을 버텼을까?

확정 범위: 외국 건축물 / 판테온 중심 + 콜로세움 비교. 자가복원은 재료의 보조 단서입니다.

## 현재 산출물: 레이아웃 전용 내러티브 다이어그램

스케치는 완성 인포그래픽이 아닙니다. A2 세로 420×594mm 안에 영역의 크기와 위치, 읽는 순서, 정보 사이의 연결, 예상 분량과 밀도를 표시했습니다. 이미지 자리는 도형과 자리표시자로만 남겼습니다. 실제 사진·상세 삽화·완성 본문은 현재 스케치에 포함하지 않습니다.

- [A2 레이아웃 다이어그램](https://www.figma.com/design/jQPriO85F6wtPy1NPo752p?node-id=21-2)
- [캔버스 바깥 영역 명세·배치 검토표](https://www.figma.com/design/jQPriO85F6wtPy1NPo752p?node-id=36-139)
- [마인드맵: 분류·배열·관계맺기 통합](https://www.figma.com/design/jQPriO85F6wtPy1NPo752p?node-id=25-30)
- [원작 레퍼런스와 적용 원리](https://www.figma.com/design/jQPriO85F6wtPy1NPo752p?node-id=20-2)
- [FigJam 원본 관계도](https://www.figma.com/board/Ob3wzRNRC0OSzDCDFp4gtF?node-id=13-354)

초기 문서형 1·2페이지는 삭제했습니다. 마인드맵, 레퍼런스, 스케치 페이지로 정리했고, 이전 스케치는 보관 페이지에 있습니다.
Design 마인드맵은 Label 속성으로 편집하는 71개 인스턴스와 곡선으로 구성했습니다. Design의 곡선은 노드 이동 시 수동으로 조정합니다. 자동 연결점 편집은 FigJam 원본을 이용할 수 있습니다.

## 검증과 출처

22개 통합 근거와 17개 관계를 검증된 출처 범위에서 Jev 1.13.0으로 검토했습니다. 초기 근거 부족 3개는 공식 원문을 보충해 재검토했습니다. 모델의 판정은 보조 검토이며 수학적 결정성이나 건축물의 구조 안전을 보증하지 않습니다.

레퍼런스: [Trajan’s Column](https://www.athcreative.com/trajans-column), [City of Anarchy](https://www.perdigallos.com/city-of-anarchy), [Notre-Dame 2025](https://www.nationalgeographic.com.es/mundo-ng/fernando-baptista-national-geographic-mejor-disenador-mundo_24859). 큰 건축물 영역, 부위별 설명의 배치, 비대칭 구도를 참고했습니다. 원작 이미지는 벤치마킹 페이지에서만 사용했습니다.

현재 다이어그램의 두 스크린샷, 영역의 A2 내부 배치, 이미지 페인트 0개, PDF 실제 판형을 확인했습니다. 실제 인쇄물과 독자 이해도는 별도 검증 대상입니다.
