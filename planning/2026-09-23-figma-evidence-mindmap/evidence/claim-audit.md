# 재료 근거 주장 검토 — 제안 데이터

검토 대상은 [material-evidence.json](material-evidence.json)의 **24개 원자 주장**이다. 사용자 수정 핵심 질문과 A2 세로형을 반영했으며, 최종 인포그래픽 문안이나 배치를 확정하는 자료는 아니다. Jev 검토 대기 상태다.

## 단계 분리

- **1단계:** `evidence_items`의 문장·분류·출처·한계만 사용한다. ID와 배열 순서는 읽는 순서가 아니다.
- **2단계:** `suggested_role`과 `normalized_process_proposal`을 검토한다. 핵심/기초/세부/보조는 같은 주제의 깊이다.
- **3단계:** 시간 순서, 원인·결과, 전체·부분, 공동 설명을 구별한다. 동일 근거의 재사용을 독립적인 검증으로 세지 않는다.

## 논문 및 근거 구분

- [S2023 — Seymour 외](https://doi.org/10.1126/sciadv.add1602): 고대 관찰은 MAT-06~07, 현대 시험은 MAT-15~21, 반응 설명은 MAT-10~14와 연결된다.
- [S2025 — Vaserman 외](https://doi.org/10.1038/s41467-025-66634-7): 현장 자료는 MAT-03, MAT-08~09; 기작 해석은 MAT-11, MAT-14에 연결된다.
- 기초 화학은 MAT-02, MAT-04~05의 `source_scope`로 구별한다. 분류용 `proposed_mechanism`이 이 화학 반응 자체를 미검증으로 뜻하지는 않는다.
- `directly_supported`는 **조건을 포함한 해당 문장을 출처가 지지한다**는 뜻이다. 모든 현장에 적용된다는 뜻이 아니다.

## 편집 전 필수 확인

| 검토점 | 연결 항목 | 처리 |
|---|---|---|
| 고대 시료와 현대 시편의 혼동 | MAT-07, MAT-15 | 재료와 장소를 각각 표기 |
| 수치만 남기고 시험 조건을 누락 | MAT-16~20 | 숫자와 적용 범위를 함께 유지 |
| 유량계 정밀도의 원문 불일치 | AUD-03 | 확정적인 방수 성능 표현 금지 |
| 충전과 구조 성능 회복을 동일시 | MAT-21~22 | 측정 결과의 범위 유지 |
| 모든 로마 재료에 일반화 | MAT-23 | 표본의 범위 유지 |
| 제조법을 자가치유 설계 의도로 해석 | MAT-24 | 의도 추정 배제 |
| 고대가 현대보다 모든 물성에서 우수하다고 단정 | AUD-04 | 두 논문으로 판정 불가 |
| 두 논문을 같은 시험의 반복 검증으로 집계 | AUD-05 | 관찰·실험·제안 기작을 분리 |

제목의 질문형 표현은 가능하지만, 본문이 “어떤 손상에서도 무너지지 않는다”는 전제를 강화하지 않도록 MAT-22~24를 함께 검토한다.

## 5단계 과정과 계보

5단계 제안은 JSON의 기존 ID를 참조한다. **1~3은 재료 형성**, **4~5는 균열 이후**다. 두 구간 사이에는 사용 기간과 균열 발생이 있다. 마지막 단계의 화학 경로는 병렬 가능성이며, 둘 다 항상 작동한다고 표현하지 않는다.

각 항목의 `canonical_claim_id`와 `duplicate_of`를 유지한다. 과정·요약·범례에서 같은 문장을 재사용할 때 새 근거로 만들지 않는다. `shared_evidence_set`은 표본·실험 계보 추적용이며 사실 수를 늘리는 값이 아니다.

## 원본 그림

원본 URL, 크기, 라이선스와 확인 상태는 JSON의 `sources.*.figure`에 저장했다. S2023 Fig. 6은 제안 기작 도식, S2025 Fig. 7은 제조법 복원 도식이다. 사진이나 직접 관측 장면으로 표시하지 않는다. 후자의 ND 조건에 유의해 원도 자체를 번역·변형한 이미지로 배포하지 않는다.

## 사용자 수정으로 사용하지 않는 범위

기존 [원문](../source-document.txt)의 **아치·볼트·하중 전달**, **벨라리움·차양·열환경**, **객석·경기장 음향**은 보존한다. 새 핵심 질문 밖이므로 이번 재료 데이터에는 편입하지 않았다. 이 처리는 원자료 삭제나 해당 주장 반박을 뜻하지 않는다.

## 인계 상태

이 분기의 수정 소유권은 이 문서와 JSON 두 파일뿐이다. 부모 에이전트가 공통 계획·진행 상태를 관리한다. Figma, 설정, 외부 계정은 변경하지 않았다.
